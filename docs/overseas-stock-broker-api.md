# 해외주식 투자 · 자산관리툴 연동 정리 (2026-10-18 기준)

> 검색 결과 기반 비교 정보이며 투자 자문이 아닙니다. 수수료·이벤트·API 범위는 수시로 바뀌므로 계좌 개설 전 각 증권사 공식 페이지에서 재확인이 필요합니다.

## 1. 목표
- 해외주식 투자용 증권사 선택
- 이후 자산관리툴을 직접 만들 예정이며, 증권사 API 연동성이 좋은 곳을 우선 고려

## 2. 증권사별 비용 비교 (미국주식 기준)

| 증권사 | 거래 수수료 | 환전 우대 | 비고 |
|---|---|---|---|
| 메리츠증권 | 0% (2026년 말까지) | 100% | 비용 최저 수준 |
| 토스증권 | 0.1% (최소 $0.01) | 95% | 앱 쉬움, 초보자 적합 |
| 키움증권 | 0.07% (이벤트) | 95% | 이벤트 없이도 꾸준히 낮은 편 |
| NH투자증권(나무) | 신규·휴면 고객 12개월 무료 | 자동환전 시 100% | 이벤트 종료 후 조건 확인 필요 |
| 카카오페이증권 | 0.1% (고정, 이벤트 없음) | 별도 확인 | 협의수수료는 월 5억 원 이상 거래자 대상 |

주의점
- 이벤트 종료 후 기본 수수료율(0.25% 수준)로 돌아가는 곳이 있음
- 환율 우대는 직접 신청해야 적용되는 경우가 있음
- 토스는 정규 시간 외 환전 시 우대율이 50%로 떨어진다는 정보가 있어 낮 시간대 환전이 유리
- 환전 스프레드가 거래 수수료보다 큰 비용이 될 수 있음

## 3. 개인용 Open API 현황 (자산관리툴 연동 관점)

| 증권사 | API 상태 | 메모 |
|---|---|---|
| 한국투자증권(KIS) | REST, 2022년 4월부터 제공 | 문서·예제 가장 풍부. 해외주식 API는 홈페이지에서 사용 동의 별도 필요 |
| 키움증권 | REST + WebSocket 전면 공개 | 미국주식 카테고리에 환전 항목 포함 (구 OpenAPI+ 병행) |
| LS증권 | xingAPI + REST | 미국 주식 시세 지원 |
| KB증권 | 2026-07-20 개인 오픈베타 | 국내·해외 시세, 주문, 잔고, 체결 내역. 11월까지 범위 확대 예정 |
| 토스증권 | 2026 상반기 개인 Open API 개방 소식 | 공개 범위 확인 필요 |
| 카카오페이증권 | 개인용 공개 API 확인 못 함 | |
| 메리츠증권 | 개인용 API 지원 여부 확인 못 함 | |

## 4. 결론 (잠정)
1. **키움증권을 메인**: 수수료(0.07%)·환율 우대(95%)와 REST/WebSocket API를 함께 챙길 수 있음
2. **한국투자증권을 대안**: API 문서가 가장 좋아 개발 난이도가 낮음 (수수료 조건은 미확인)
3. 앱 편의성이 필요하면 **토스를 서브로 병행**
4. 비용 최우선이면 메리츠를 추가 검토 (API 지원은 별도 확인)

## 5. 자산관리툴 설계 메모
- 증권사별 인증·파라미터·응답 구조가 달라서 **공통 인터페이스(어댑터) 한 겹**으로 감싸는 구조가 좋음
  - 참고: 오픈소스 `krsec` (한국 증권사 REST API 통합 게이트웨이, Go)
- 필요한 기능 후보: 잔고 조회, 체결 내역, 시세, 환전, 해외주식 통합 평가
- 앱키/시크릿은 환경변수나 비밀 저장소로 관리하고 코드에 넣지 않기
- 처음엔 모의투자 키로 개발한 뒤 실전 키로 전환 (모의/실전 키와 URL이 다름)
- 증권사별 호출 제한(rate limit)과 토큰 갱신 처리 필요
