# 설계: 도착 자동 기록 (향후 구현)

상태: **설계만 확정, 구현 보류** (2026-11-18 결정)

## 목적
기사가 도착 버튼을 누르지 않아도 도착 시각이 남게 하고, 완료 누락도 알아챈다.

## 전제와 제약
- 기사 화면은 웹 페이지(Apps Script 웹앱)다. 휴대폰은 TMAP처럼 다른 앱이 앞에 있으면
  뒤에 있는 웹 페이지의 동작과 위치 확인을 멈춘다. 따라서 "운전 중 도착 순간 자동 기록"은
  웹으로는 불가능하고 전용 앱이 필요하다(이번 설계 범위 밖).
- 휴대폰 위치 기능은 내비 사용으로 이미 켜져 있다. 기사 화면에서 처음 한 번 위치 사용을 허용하면,
  화면이 다시 보이는 순간 바로 위치를 받을 수 있다.
- 구글 웹앱 화면(iframe) 안에서 위치 기능이 막히지 않는지 실제 휴대폰으로 먼저 확인해야 한다.
  막혀 있으면 1단계는 빼고 2·3단계만 적용한다.

## 1단계: 화면이 보일 때 위치로 자동 도착
- 기사 화면이 앞에 있을 때(처음 열 때, TMAP에서 돌아올 때 `visibilitychange`, 켜 둔 동안 `watchPosition`)
  위치를 확인한다.
- 현재 차례 경유지(출발 기록 있음, 도착 기록 없음)에서 반경 안이면 도착시각을 자동 기록하고 "자동 도착" 표시.
- 반경: 설정 탭 `도착반경(m)`, 기본 150m. 부지가 넓은 곳은 늘린다.
- GPS 정확도(accuracy)가 반경보다 크게 나쁘면 판정하지 않는다.
- 서버 함수 예: `autoArrive(p, index, lat, lng, accuracy)` — 토큰 검증, 현재 차례 확인, 서버에서도 거리 재계산.

## 2단계: 도착 누락 시 추정
- 도착 기록 없이 완료를 누르면 지금은 도착 = 완료시각. 이를
  **출발시각 + 그 구간 예상 이동시간(구간캐시)** 으로 바꾸되 완료시각보다 늦지 않게 한다.

## 3단계: 기록 방식 표시
- 운행일지에 `도착기록` 칸 추가: `수동`(버튼) / `자동`(위치) / `추정`(2단계).
- 누락이 잦은 기사·업체 확인용.

## 완료 누락 알림
- 도착 후 완료를 누르지 않고 업체 반경을 벗어난 것을 화면이 다시 보일 때 확인하면
  "○○ 완료를 누르지 않았습니다" 알림을 띄운다.
- 완료는 하차·상차 확인이므로 **자동 처리하지 않고 알림만** 띄운다.

## 개인정보
- 위치는 도착 판정에만 쓰고 이동 경로는 저장하지 않는다(필요하면 판정 순간의 거리만 기록).

## 구현 시 영향 파일
- `src/index.html` — 위치 권한 요청, 판정 호출, 알림
- `src/webapp.gs` — `autoArrive`, 완료 시 추정 도착
- `src/log.gs` / `src/config.gs` — `도착기록` 칸(OPTIONAL_HEADERS), `도착반경(m)` 설정
- `test/e2e.test.js` — 반경 안/밖, 정확도 불량, 추정 도착
