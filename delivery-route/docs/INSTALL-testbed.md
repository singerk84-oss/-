# 배송 경로·운행일지 시스템 — 테스트 설치 안내

이 문서는 시스템을 처음 받는 회사의 담당자를 위한 안내입니다. 30분 정도 걸립니다.

## 준비물
- 회사 구글 계정 1개(시트를 소유·관리할 계정)
- 회사 주소, 차량 정보(최대적재중량, 적재함 길이), 거래처 주소
- 기사 휴대폰에 TMAP 앱(길안내용)
- (선택) SK오픈API TMAP 앱 키 — 실제 화물차 도로로 계산할 때. 없으면 직선거리 추정으로 시험합니다.

## 1. 사본 만들기
1. 받은 템플릿 링크를 엽니다.
2. **파일 → 사본 만들기**를 누르고, 이름과 저장할 폴더를 정해 **사본 만들기**를 누릅니다.
3. 이후 작업은 모두 **내 사본**에서 합니다(템플릿 원본은 보기 전용입니다).
4. **파일 → 설정**에서 시간대가 **(GMT+09:00) 서울**인지 확인합니다.

## 2. 프로그램 권한 허용과 웹앱 배포
1. 사본에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
3. 유형 선택(톱니바퀴)에서 **웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르면 권한 허용 창이 뜹니다. 계정을 고르고 **허용**합니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 회사가 직접 쓰는 스크립트라 뜨는 정상 경고입니다.
5. 표시된 **웹 앱 URL**(…/exec로 끝남)을 복사해 시트 **설정 탭 웹앱URL** 칸에 붙여 넣습니다.

> 회사가 Google Workspace를 쓰고 외부 공유를 막아 두었다면 "모든 사용자"가 보이지 않을 수 있습니다. 이 경우 기사가 구글 로그인 없이 링크를 열 수 없으니 관리자에게 확인하세요.

## 3. 기본 정보 입력
시트를 **새로고침**하면 위쪽에 **배송관리** 메뉴가 생깁니다.

1. **설정 탭**: 회사주소(도로명), 운행시작·종료, 상차시간, 기본체류시간
2. **차량 탭**: 차량ID(예: 1호차), 차량명, 차량번호, 톤수, **최대적재중량(kg)**, **적재함길이(mm)**, 기사명, 기사휴대폰
   - TMAP 화물차 경로를 쓸 때만: 차량높이·폭·길이(cm), 차량총중량(kg), TMAP차종
3. **거래처 탭**: 거래처명, 주소(도로명). 위도·경도는 비워 둡니다. 매입처도 여기에 등록합니다.
4. 메뉴 **① 시트 템플릿 확인** → **② 주소 → 좌표 변환** (위도·경도가 채워지는지 확인)

## 4. 하루 운영
1. **오늘배송 탭**에 그날 건을 한 줄씩 입력: 일자, 거래처명, 화물중량(kg), 화물최대길이(mm)
   - 구분: 배송(비워도 됨) / 매입
   - 우선: 먼저 가야 하는 배송이면 체크(그 차량 1회차, 회차 안에서 먼저)
   - 수동지정: 차량·회차를 직접 정하려면 배정차량ID·회차를 적고 체크
2. **③ 배차·경로 계산** → 차량·회차·방문순서·예상도착시각이 채워지고 **회차 탭**에 기사용 링크가 생깁니다.
3. **④ 회차 링크 전송**(담당자 메일로 전송) 또는 회차 탭 링크를 기사에게 카카오톡 등으로 전달합니다.
4. 기사: 링크 열기 → 업체명 누르기(출발 기록 + TMAP 안내) → **완료**(매입은 **상차 완료**) → 다음 업체 → 회사 복귀 → 마지막 회차면 계기판 주행거리 입력
5. 운행 중 매입이 생기면: 오늘배송에 구분=매입, 배정차량ID 빈 행을 넣고 **⑤ 운행 중 매입 추가**. 기존 링크 그대로, 기사 화면에 자동 반영됩니다.

## 5. 시험용 설정
- **경로제공자**: 처음에는 `estimate`(직선거리 추정)로 흐름을 확인하고, TMAP 키를 받으면 `tmap`으로 바꿉니다.
  - TMAP 키는 **Apps Script → 프로젝트 설정 → 스크립트 속성**에 `TMAP_APP_KEY`로 넣습니다(시트에 적지 마세요).
- **작업일자**: 비우면 오늘. 다음 날 배차를 전날 미리 계산할 때 날짜를 넣고, 끝나면 비웁니다.

## 알려진 제한(테스트 단계)
- TMAP 화물차 경로 API와 TMAP 앱 실행 링크는 공식 규격과 최종 대조 중입니다. 오류가 나면 **오류로그 탭** 내용을 공유해 주세요.
- estimate 모드의 시간·거리는 직선거리 기반 추정치입니다.
- 프로그램 업데이트는 사본에 자동 반영되지 않습니다. 업데이트가 필요하면 담당자에게 요청해 주세요.
