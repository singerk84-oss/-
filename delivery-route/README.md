# 배송 경로 최적화 및 운행일지 시스템

자체 화물차(1톤·5톤·10톤)의 일일 배송을 자동화하는 Google Apps Script 프로젝트입니다.
차량 배정·회차 산정 → 회차별 최적 경로 → 기사용 웹앱 링크 → 운행일지·일일마감 자동 기록까지 처리합니다.

설계 기준: Google 드라이브 "배송 경로 운행일지 시스템" 폴더의 설계 문서와 이관 문서. 요약은 [docs/CLAUDE.md](docs/CLAUDE.md).

## 사용 흐름(스프레드시트 메뉴 `배송관리`)
1. **① 시트 템플릿 확인** — 필수 시트·컬럼 점검, 보조 시트(회차·구간캐시·오류로그) 생성
2. **② 주소 → 좌표 변환** — 설정의 회사주소와 거래처 주소 중 좌표가 빈 곳만 변환
3. **③ 배차·경로 계산** — 오늘배송 탭에 배정차량·회차·방문순서·예상도착시각·경고 기록, 회차 시트에 링크 생성, 운행일지 행 준비
4. **④ 회차 링크 전송** — 담당자에게 회차별 링크 전송
5. 기사: 링크 열기 → 업체명 탭(출발 기록 + 길안내) → 도착(선택) → 완료 → 다음 업체 → 회사 복귀 → 마지막 회차면 계기판 주행거리 입력

## 설치
```bash
npm install -g @google/clasp
clasp login
cp .clasp.json.example .clasp.json   # scriptId: 스프레드시트 [확장 프로그램 > Apps Script]의 프로젝트 ID
clasp push
```
그다음 Apps Script 편집기에서
1. **배포 > 새 배포 > 웹 앱**(실행: 나, 액세스: 모든 사용자). 기사는 구글 계정 없이 링크로 접속하며, 서명 토큰으로 무단 접근을 막습니다.
2. **프로젝트 설정 > 스크립트 속성** 등록

| 속성 | 필수 | 설명 |
| --- | --- | --- |
| `TMAP_APP_KEY` | ○ | SK오픈API TMAP 앱 키(화물차 경로안내) |
| `KAKAO_REST_KEY` | | 카카오 REST API 키(주소→좌표 변환, 나에게 보내기). 없으면 좌표 변환은 구글 지오코더 사용 |
| `ROUTE_PROVIDER` | | `tmap`(기본, 화물차) / `kakao`(승용차 기준) / `estimate`(API 없이 추정, 시험용) |
| `NAV_APP` | | 기사 길안내 앱 `tmap`(기본) / `kakaomap` |
| `NOTIFY_MODE` | | `email`(기본) / `kakao_memo` / `alimtalk`(2단계, 미구현) |
| `NOTIFY_EMAIL` | | email 모드 수신자(없으면 스크립트 소유자) |
| `KAKAO_CLIENT_SECRET` | | 카카오 앱에서 클라이언트 시크릿을 켠 경우 |
| `SPREADSHEET_ID` | | 웹앱이 다른 시트를 쓰는 경우 |
| `WEBAPP_URL` | | 링크에 쓸 웹앱 URL을 직접 지정할 때(기본: 현재 배포 URL) |

`LINK_SECRET`(링크 서명), `KAKAO_REFRESH_TOKEN`(나에게 보내기)은 자동으로 저장됩니다. **LINK_SECRET을 바꾸면 기존 링크가 모두 무효**가 됩니다.

### 화물차 경로(TMAP) 준비
- SK오픈API(openapi.sk.com) 가입 → TMAP 앱 등록 → 앱 키 발급. 화물차 경로안내는 무료 요금제 하루 1,000건
- 호출량: 배송지 N곳이면 차량 제원별로 최대 N×(N+1)회. 10곳·차량 3대면 약 330회. 제원이 같은 차량끼리는 공유하고, 같은 날 같은 구간은 캐시
- **차량 시트**에 제원 입력: `차량높이(cm)`, `차량폭(cm)`, `차량길이(cm)`, `차량총중량(kg)`, `TMAP차종`
  (컬럼이 없으면 메뉴 ① 실행 시 자동 추가. `TMAP차종`은 TMAP 문서의 차종 코드표 값)
- 중량 제한 판단에는 최대적재중량을 화물중량으로 넣습니다(회차별 실제 중량보다 보수적)
- 어떤 차량이 진입할 경로가 없는 거래처(높이 제한 굴다리 등)는 그 차량 후보에서 빠지고, 실을 수 있는 차량이 모두 못 들어가면 경고가 표시됩니다
- 기사 휴대폰: TMAP 앱 설치 후 [차량 정보]를 화물차로 등록해 두면 실제 안내도 제한 구간을 피합니다. 기사 화면에는 카카오맵 링크도 보조로 나옵니다
- ⚠ API 주소·파라미터 이름(`src/matrix.gs`의 `TMAP_TRUCK`)과 앱 실행 스킴(`src/links.gs`의 `tmapLink_`)은 공식 문서와 대조가 필요합니다. 다르면 그 블록만 고치면 됩니다

### 카카오 준비
- 카카오 디벨로퍼스 계정·앱 등록 → REST API 키 발급(주소 → 좌표 변환)
- 카카오 길찾기(`ROUTE_PROVIDER=kakao`)는 승용차 기준이고, 업무(상업) 용도는 무료 한도 안이라도 별도 제휴가 필요하다고 안내되어 있어 기본값에서 뺐습니다
- 나에게 보내기: 카카오 로그인 활성화, 동의항목 `talk_message`, Redirect URI와 플랫폼(Web) 도메인에 웹앱 URL(`https://script.google.com`) 등록 → 메뉴 **카카오 로그인** 1회 실행
- 알림톡(2단계): 카카오 비즈니스 채널, 발송 대행사, 메시지 양식 승인

### API 없이 먼저 확인하기
1. 설정 시트에 회사 위도·경도를 직접 입력(또는 주소 변환)
2. 스크립트 속성 `ROUTE_PROVIDER=estimate`
3. 메뉴 **예시 데이터 넣기** → **③ 배차·경로 계산** → 1톤 2회, 5톤 3회, 10톤 1회 = 회차 6개·링크 6개
4. 확인 후 예시 행(`예시-` 거래처·차량)을 지우고 `ROUTE_PROVIDER`를 삭제(기본 tmap)

## 개발
```bash
npm test
```
- `test/route.test.js` — 8곳 이하 전수 탐색 결과를 무차별 대입과 대조, 8곳 초과 휴리스틱
- `test/assign.test.js` — 예시 데이터 회차 수, 중량·길이·시간 조건, 수동지정, 예상도착시각
- `test/matrix.test.js` — TMAP 화물차 요청 형식, 제원별 캐시·공유, 진입 불가 구간 처리
- `test/e2e.test.js` — Apps Script 서비스를 메모리로 흉내 내 메뉴 → 웹앱 → 마감 전체 흐름 시험

## 알려진 제약 / 확인 필요
- TMAP 화물차 API 규격은 공식 문서로 최종 확인 전입니다(위 ⚠ 참고).
- `도착` 버튼은 선택입니다. 누르지 않고 `완료`를 누르면 도착시각 = 완료시각으로 기록됩니다.
- 운행이 시작된 날은 재계산을 막습니다(기록 보호).
